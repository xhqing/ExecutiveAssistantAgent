# Language Partner — 找语伴方案库

帮用户找到「对方想学中文的英语母语者」这类双向语言交换伙伴，以及线下面对面的练习场景。核心是供需匹配：我方提供中文，对方提供英文，各取所需。

## 执行流程（用户触发时照此走）

1. **快速澄清关键变量**（能从上下文推断的直接推断，别连环追问）：
   - 目标语言方向（默认：用户中文母语练英语）
   - 线上还是线下（用户明确偏好线下时，线下渠道排前面）
   - 免费 exchange 还是可以接受付费外教
   - 所在城市（线下场景必问，决定检索词）
2. **按偏好从下方渠道库选组合**，给出 2-3 条并行路线（单渠道成功率低，撒网是标配）。
3. **主动提供交付物**：帮用户写英文招募帖 / HelloTalk 等平台的英文自我介绍（模板见文末），这是每次的标配输出，不要等用户开口要。

## 核心认知（为什么这么做）

- **「找语伴」的本质是双向供需匹配**：我方 = 中文母语 + 想学英语；对方 = 英语母语 + 想学中文。语言交换平台的功能就是按这两个条件互相筛选推送。
- **工具分三层**：配对 App（算法推人，量大）、社区发帖（自己写招募，对象更主动更认真）、线下场景（面对面，效果好且能建立真实社交关系）。
- **供需现实**：学英语的中国人远多于学中文的英语母语者，供不应求。推论：**在中文平台等对方上门不如主动去英文世界找**（Reddit、Meetup、老外社区里发帖的人往往是真想学的）；资料写得有诚意是脱颖而出的关键。
- **免费 exchange 的固有痛点**：时区对不上、被放鸽子（ghosting）、水平不匹配、聊天变成慢速文字。解法见「实操技巧」。如果用户要稳定和效率，付费外教是保底路线。

## 渠道库

### A. 线上配对 App（量大，先铺开）

| 平台 | 规模与机制 | 费用要点 | 备注 |
|------|-----------|---------|------|
| **HelloTalk** | 约 3000 万注册，150+ 语言；设置「母语中文、学习英语」即自动推「英语母语、在学中文」的人 | 文字 / 语音消息 / 语音房免费；视频通话需 VIP | 中英交换是它的王牌场景；人多也杂，垃圾私信多 |
| **Tandem** | 约 1000 万注册；注册有人工审核，社区更认真 | 语音 / 视频通话锁在 Pro 付费版 | 人比 HelloTalk 少，但质量高 |
| **Speaky** | 免费语言交换社区，界面类似 | 免费 | 备选 |
| **HiNative** | 向母语者提问的问答社区 | 免费为主 | 偏文字纠错，不是实时对话，可当补充 |
| 随机视频类（OmeTV / Azar） | 陌生人随机视频，几秒接通 | 免费 + 内购 | 偏社交搭讪、内容不可控，**不作主推**，仅当开放性跨文化对话的补充，须提醒安全风险 |

### B. 社区发帖（免费、直接、对象更认真）

- **Reddit r/language_exchange**：帖子格式就是「Offering: English (native) | Seeking: Mandarin」。既可以直接搜/回复这类帖子，也可以自己发中文版招募。实测活跃，能看到「自学中文半年的美国人找每周一次语音语伴」这类高质量帖子。
- **Conversation Exchange / My Language Exchange**（网页老社区）：可精确筛选「对方母语 = 英语 + 对方在学中文 + 愿意文字/语音/视频 + 在线时间匹配」，用网页版的人通常想得清楚、长期稳定性高。界面老旧但有效，被低估。
- **Facebook**：搜「城市名 + language exchange / English corner」群组。
- **Discord**：中文学习服务器（搜 Mandarin learning server）、语言交换服务器，语音房随时进。

### C. 线下场景（用户偏好线下时优先给）

- **Meetup**（海外城市 / 国内一线城市有）：搜「Chinese English language exchange + 城市名」。实例：纽约有每周四晚的中英语言交换固定活动，8-10 人小规模；美国不少城市（如 Portland）有每周固定的 Mandarin-English 会话小组。
- **城市英语角 / 英语沙龙**（国内城市主力）：搜「城市名 + 英语角 / 英语沙龙」，发布渠道主要是豆瓣同城、微信公众号。实例：北京英语角（国图沙龙每周四晚、通州沙龙每周日上午、报名审核制、约 10 元场地费、轮流主持话题制、白领为主 15-35 人、全程英文交谈）。
- **大学**：国际学生语伴项目（tandem program）、留学生社团活动；在校生或校友可联系国际交流处。大学里「想学中文的留学生」密度最高。
- **兴趣与场景渠道**：InterNations（在华外国人社区，部分付费）、国际教会活动、外国志愿者活动、语言学校公开课、外国人常去的酒吧与国际活动夜。
- **线上转线下**：HelloTalk 等有「附近的人」功能，聊得投机可约线下咖啡——必须遵守安全规则（见下）。

### D. 付费外教（交换不稳时的保底，或与免费路线并行）

- **Cambly**：随时打开立刻连英语母语者视频对话，不用约课；约 52 美元/月（每周 30 分钟）起。最省事但贵、外教水平参差。
- **italki / Preply**：约课制固定老师，可系统提升，需要花时间挑老师。

## 实操技巧（来自社区老用户的共识经验）

1. **资料是敲门砖**：写清楚你能提供什么——纠音、地道表达、中国文化、某个共同兴趣话题（美食、球赛、游戏都行）。老外被私信淹没时只挑有诚意的回，一句 "hi" 没有意义。
2. **主动结构化**：文字聊几天后明确提议「每周固定 N 次，每次中文 30 分钟 + 英文 30 分钟」。固定时间表是长期语伴的关键，也顺便练了视频/面对面沟通表达。
3. **别挑「典型」对象**：看着没共同语言的年长用户可能恰恰是耐心纠错的英语老师。别只盯着年轻用户。
4. **多平台并行**：App 挂着 + 网页社区筛一轮 + Reddit 发一帖，目标是一两周内攒 2-3 个稳定语伴（单线容易断）。
5. **通话工具**：微信（学中文的外国人一般都有）或 WhatsApp；要录像复盘用 Zoom（40 分钟内免费，可本地录制——复盘自己的表达对「视频沟通能力」提升最快）。

## 安全注意（涉及线下必须主动提醒）

- 线下首次见面：公共场合、白天、告知朋友行程；不轻易透露住址与财务状况。
- 线上遇到推销、传教、诈骗、骚扰：直接拉黑举报，语言交换平台此类现象真实存在（北京英语角甚至明文禁止现场推销，可见普遍性）。
- 随机视频类平台内容不可控，女性用户尤其注意。

## 交付物模板

### 英文招募帖（Reddit r/language_exchange / 网页社区通用）

```
Offering: Mandarin (native) | Seeking: English (native)

Hi! I'm [name/age/city]. I'm a native Mandarin speaker looking for a serious
language exchange partner to practice spoken English. In return I can help
you with Mandarin — pronunciation, natural expressions, and everyday/cultural
topics you actually want to use.

About me: [1-2 句兴趣背景，找共同话题]
What I'm looking for: [视频/语音/线下]，e.g. a weekly video call, 30 min
English + 30 min Mandarin. I'm committed and punctual — hope you are too!

Feel free to DM me :)
```

### App 自我介绍（HelloTalk / Tandem 资料）

```
Native Mandarin speaker from [city]. Learning English, currently [level].
Happy to help with pronunciation, slang, and everything about Chinese culture.
Looking for a steady partner for weekly voice/video calls — 50/50 time split.
Interests: [兴趣列表，给对方共同话题]
```

## 边界与协作

- 用户明确要 AI 陪练工具或培训机构课程时，不在本 skill 范围内，但可顺带提醒「免费语伴路线存在」。
- 需要实时核验某平台 / 活动现状（是否还活着、活动时间）时，用 anysearch / agent-reach 搜「平台名 + review 2025」或「城市 + 英语角」，不要只凭本 skill 的快照数据下结论（本 skill 数据调研于 2026-09，平台规则与价格会变）。
